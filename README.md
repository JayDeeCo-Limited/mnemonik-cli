# Mnemonik CLI

This is the source of the Mnemonik installer, the `mnemonik` command that
sets up Mnemonik's hooks, MCP connection and scanner in Claude Code, Codex
and Cursor on Linux, macOS and Windows.

The source here is mirrored from JayDeeCo Limited's private build on every
release, so anyone can read exactly what the published `@mnemonik/cli`
package was built from. Each release of the scanner (which stays private
source) is attached to this repository as signed artifacts with digests and
software bills of materials.

Nothing has been released yet. The first mirror commit and the first
release arrive when Mnemonik launches.

Mnemonik: https://mnemonik.ai
